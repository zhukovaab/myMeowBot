# Быстрый старт - Развертывание Meow Bot

## Минимальные требования
- Ubuntu/Debian сервер
- Python 3.8+
- sudo права

## Пошаговая инструкция (5 минут)

### 1. Подготовка сервера
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install python3 python3-pip python3-venv git -y
```

### 2. Загрузка проекта
```bash
git clone <ваш-репозиторий> my-meow-bot
cd my-meow-bot
```

### 3. Настройка Python
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 4. Настройка токена и логирования
```bash
nano .env
```
Добавьте:
```
BOT_TOKEN=ваш_токен_бота
LOG_MAX_DAYS=7
```

### 5. Тестирование
```bash
python bot.py
```
Нажмите Ctrl+C для остановки

### 6. Установка как сервис
```bash
chmod +x manage_bot.sh
sudo ./manage_bot.sh install
sudo ./manage_bot.sh start
```

### 7. Проверка работы
```bash
sudo ./manage_bot.sh status
```

## Готово! 🎉

Ваш бот теперь работает как системный сервис и будет автоматически запускаться при перезагрузке сервера.

### Новые функции встреч 📅

Ваш бот теперь умеет:
- **Добавлять встречи**: `/add_meeting`
- **Создавать регулярные встречи**: `/add_recurring`
- **Показывать список**: `/meetings` с интерактивными кнопками
- **Редактировать**: кнопки ✏️ в списке или `/edit_meeting ID`
- **Удалять**: кнопки 🗑️ в списке или `/delete_meeting ID`
- **Напоминать за 2 минуты** с картинками котиков! 🐱
- **Автоматически удалять** прошедшие встречи
- **Логировать все действия** с автоматической ротацией

**Регулярные встречи (6 типов):**
- 📅 Ежедневные, еженедельные, ежемесячные
- 📅 Раз в 2 недели
- 💼 По будням (пн-пт)
- 🗓️ По выбранным дням недели (интерактивный выбор)
- 🔢 Настраиваемый интервал (каждые N дней/недель/месяцев)
- 🏁 Опциональная дата окончания
- 🔄 Автоматическое создание следующих встреч

**Поддерживаемые форматы времени:**
- `15:30` или `15 30` - сегодня/завтра в указанное время
- `завтра 10:00` или `завтра 10 00` - завтра в 10:00
- `25.12 14:00` или `25.12 14 00` - 25 декабря в 14:00
- `25.12.2024 14:00` или `25.12.2024 14 00` - полная дата

## Управление

**Системные команды:**
```bash
sudo ./manage_bot.sh start    # Запуск
sudo ./manage_bot.sh stop     # Остановка  
sudo ./manage_bot.sh restart  # Перезапуск
sudo ./manage_bot.sh status   # Статус
sudo ./manage_bot.sh logs     # Логи systemd
```

**Управление логами:**
- Логи сохраняются в `logs/bot_YYYYMMDD.log`
- Автоматическое удаление через `LOG_MAX_DAYS` дней
- Просмотр: `tail -f logs/bot_*.log`
- Статистика: `du -sh logs/`
