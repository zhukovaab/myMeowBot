# Обновление системы напоминаний - исправление часовых поясов

## Проблема
Система напоминаний не работала из-за неправильной обработки часовых поясов. Встречи сохранялись в местном времени пользователя, но сервер работал в UTC, что приводило к неправильному расчету времени напоминаний.

## Решение
Добавлена полная поддержка часовых поясов:

1. **База данных**: Добавлена колонка `timezone` в таблицу `user_settings`
2. **Парсинг времени**: Все времена теперь конвертируются в UTC для сохранения
3. **Система напоминаний**: Работает с UTC временем и корректно отображает время в часовом поясе пользователя
4. **Настройки**: Добавлена возможность выбора часового пояса через интерфейс бота

## Инструкции по обновлению на сервере

### 1. Остановите бота
```bash
sudo systemctl stop meow-bot
```

### 2. Обновите код
```bash
cd /root/myMeowBot
git pull origin master
```

**ВАЖНО:** Если git pull не работает из-за локальных изменений, выполните:
```bash
git stash
git pull origin master
git stash pop
```

### 3. Установите новую зависимость
```bash
source venv/bin/activate
pip install pytz==2024.2
```

### 4. Запустите бота
```bash
sudo systemctl start meow-bot
```

### 5. Проверьте статус
```bash
sudo systemctl status meow-bot
```

### 6. Проверьте логи
```bash
sudo journalctl -u meow-bot -f --lines=20
```

## Что изменилось

### Новые функции:
- **Настройка часового пояса**: Пользователи могут выбрать свой часовой пояс в настройках
- **Корректная обработка времени**: Все времена корректно обрабатываются с учетом часового пояса
- **Улучшенная система напоминаний**: Напоминания приходят точно в нужное время

### Технические изменения:
- Добавлена библиотека `pytz` для работы с часовыми поясами
- Обновлена функция `parse_datetime()` для конвертации времени в UTC
- Система напоминаний теперь работает с UTC временем
- Добавлены новые методы в базу данных для работы с часовыми поясами

## Тестирование

После обновления:

1. Создайте тестовую встречу на ближайшее время (через 2-3 минуты)
2. Убедитесь, что напоминание приходит вовремя
3. Проверьте настройки часового пояса в `/settings`
4. Измените часовой пояс и создайте еще одну тестовую встречу

## Популярные часовые пояса

Бот поддерживает следующие часовые пояса:
- Москва (UTC+3) - по умолчанию
- Киев (UTC+2)
- Минск (UTC+3)
- Алматы (UTC+6)
- Ташкент (UTC+5)
- И многие другие...

## Миграция данных

База данных автоматически обновится при первом запуске. Существующие пользователи получат часовой пояс "Europe/Moscow" по умолчанию.

## Поддержка

Если возникнут проблемы:
1. Проверьте логи: `sudo journalctl -u meow-bot -f`
2. Перезапустите бота: `sudo systemctl restart meow-bot`
3. Убедитесь, что установлена библиотека pytz: `pip list | grep pytz`
