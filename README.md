# My Meow Bot 🐱

Telegram бот для получения случайных картинок кошек и управления встречами с напоминаниями.

## Функциональность

### Основные команды
- `/start` - Начать работу с ботом
- `/meow` - Получить случайную картинку кошки
- `/help` - Показать справку

### Управление встречами
- `/add_meeting` - Добавить новую встречу
- `/add_recurring` - Добавить регулярную встречу
- `/meetings` - Показать список встреч
- `/edit_meeting [ID]` - Редактировать встречу
- `/delete_meeting [ID]` - Удалить встречу

### Регулярные встречи
- **Ежедневные** - каждый день или через N дней
- **Еженедельные** - каждую неделю или через N недель
- **Раз в 2 недели** - каждые 2 недели или кратно
- **Ежемесячные** - каждый месяц или через N месяцев
- **По будням** - только понедельник-пятница
- **По определенным дням** - выбор конкретных дней недели (пн, ср, пт и т.д.)
- Возможность установить дату окончания повторений
- Автоматическое создание следующих встреч в серии

### Напоминания и автоматизация
- Бот автоматически напоминает о встречах за 2 минуты до их начала
- **Картинки котиков** в каждом напоминании для поднятия настроения! 🐱
- Автоматическое удаление прошедших встреч (кроме регулярных)
- Поддерживает различные форматы времени: `15:30` или `15 30`, `завтра 10:00` или `завтра 10 00`, `25.12 14:00` или `25.12 14 00`

### Интерактивное управление
- **Кнопки в списке встреч** для быстрого редактирования и удаления
- Интуитивный интерфейс без необходимости запоминать ID встреч
- Быстрое добавление новых встреч прямо из списка

### Система логирования
- **Автоматическая ротация логов** с ежедневным созданием новых файлов
- **Автоматическая очистка** старых логов (по умолчанию удаляются каждый день)
- **Настраиваемые параметры** через переменные окружения
- **Мониторинг через файловую систему** - просмотр логов на сервере

## Примеры использования

### Добавление встречи
1. Отправьте `/add_meeting`
2. Введите название встречи: `Встреча с командой`
3. Введите описание: `Обсуждение нового проекта` (или `-` чтобы пропустить)
4. Введите время: `завтра 14:30`

### Просмотр встреч
- `/meetings` - показать все встречи с интерактивными кнопками
- **Кнопки действий:**
  - ➕ Добавить встречу
  - ✏️ Редактировать (по названию встречи)
  - 🗑️ Удалить (с подтверждением)

### Интерактивное управление
- **Из списка встреч:** нажмите кнопку рядом с нужной встречей
- **Классические команды:** `/edit_meeting 5`, `/delete_meeting 5`
- **Быстрое добавление:** кнопка "➕ Добавить встречу" в списке

### Добавление регулярной встречи
1. Отправьте `/add_recurring`
2. Введите название: `Ежедневная планерка`
3. Введите описание: `Обсуждение задач` (или `-`)
4. Введите время первой встречи: `завтра 09:00`
5. Выберите тип повторения:
   - 📅 **Ежедневно** → интервал (1, 2, 3...)
   - 📅 **Еженедельно** → интервал (1, 2, 3...)
   - 📅 **Раз в 2 недели** → интервал (1, 2, 3...)
   - 📅 **Ежемесячно** → интервал (1, 2, 3...)
   - 💼 **По будням** → сразу к дате окончания
   - 🗓️ **По определенным дням** → выбор дней недели
6. Для кастомных дней: выберите дни недели кнопками
7. Введите дату окончания: `31.12.2024` или `-` (без ограничений)

### Примеры регулярных встреч
- **Ежедневная планерка**: Ежедневно в 09:00
- **Еженедельное совещание**: Еженедельно по понедельникам в 14:00
- **Тренировки**: По пн, ср, пт в 18:00
- **Рабочие встречи**: По будням в 10:00
- **Ретроспектива**: Раз в 2 недели по пятницам в 16:00

## Локальная разработка

### Требования

- Python 3.11+
- pip

### Установка

1. Клонируйте репозиторий:
```bash
git clone <your-repo-url>
cd my-meow-bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` и добавьте токен бота:
```bash
BOT_TOKEN=your_telegram_bot_token_here

# Настройки логирования (опционально)
LOG_LEVEL=INFO                    # DEBUG, INFO, WARNING, ERROR, CRITICAL
LOG_TO_FILE=true                  # Логировать в файл (true/false)
LOG_TO_CONSOLE=true               # Логировать в консоль (true/false)
LOG_DIR=logs                      # Директория для логов
LOG_MAX_DAYS=1                    # Количество дней хранения логов
```

4. Запустите бота:
```bash
python bot.py
```

## Развертывание

### Вариант 1: Развертывание на сервере (рекомендуется)

Для развертывания на вашем собственном сервере используйте подробную инструкцию в файле [DEPLOYMENT.md](DEPLOYMENT.md).

**Быстрый старт:**
```bash
# 1. Загрузите файлы на сервер
# 2. Создайте виртуальное окружение
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 3. Создайте файл .env с токеном и настройками
echo "BOT_TOKEN=ваш_токен_бота" > .env
echo "LOG_MAX_DAYS=7" >> .env  # Хранить логи 7 дней (опционально)

# 4. Установите как systemd сервис
sudo ./manage_bot.sh install

# 5. Запустите бота
sudo ./manage_bot.sh start
```

**Управление ботом:**
```bash
sudo ./manage_bot.sh start    # Запуск
sudo ./manage_bot.sh stop     # Остановка
sudo ./manage_bot.sh restart  # Перезапуск
sudo ./manage_bot.sh status   # Статус
sudo ./manage_bot.sh logs     # Логи systemd
```

**Управление логами бота:**
- Логи автоматически сохраняются в директории `logs/`
- Просмотр файлов: `ls -la logs/` и `tail -f logs/bot_*.log`
- Статистика: `du -sh logs/` для размера логов

### Вариант 2: Деплой на Render

#### Подготовка

1. Создайте аккаунт на [Render.com](https://render.com)
2. Подключите ваш GitHub/GitLab репозиторий

#### Деплой

##### Способ 1: Через render.yaml (рекомендуется)

1. Убедитесь, что файл `render.yaml` находится в корне проекта
2. Загрузите код в Git репозиторий
3. В Render Dashboard:
   - Нажмите "New +" → "Blueprint"
   - Подключите ваш репозиторий
   - Render автоматически создаст сервис на основе `render.yaml`

##### Способ 2: Ручное создание

1. В Render Dashboard нажмите "New +" → "Web Service"
2. Подключите ваш Git репозиторий
3. Настройте параметры:
   - **Name**: `my-meow-bot`
   - **Environment**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
   - **Plan**: `Free`

4. В разделе "Environment Variables" добавьте:
   - **Key**: `BOT_TOKEN`
   - **Value**: ваш токен Telegram бота

5. Нажмите "Create Web Service"

#### Обновление

При каждом push в репозиторий Render автоматически пересоберет и перезапустит приложение.

#### Мониторинг

- Логи доступны в разделе "Logs" вашего сервиса
- Статус деплоя отображается в разделе "Events"

## Технические детали

### API
- Бот использует [The Cat API](https://thecatapi.com/) для получения картинок кошек

### База данных
- Встречи хранятся в локальной SQLite базе данных (`meetings.db`)
- Автоматическое создание таблиц при первом запуске
- Каждый пользователь видит только свои встречи
- Поддержка регулярных встреч с настройками повторения

### Система напоминаний
- Проверка предстоящих встреч каждые 30 секунд
- Напоминания отправляются за 2 минуты до начала встречи
- Автоматический запуск и остановка вместе с ботом
- Обработка регулярных встреч каждые 5 минут
- Автоматическая очистка прошедших встреч

### Система логирования
- **Ротация логов**: новый файл каждый день (`bot_YYYYMMDD.log`)
- **Автоматическая очистка**: удаление старых файлов по расписанию
- **Настраиваемое хранение**: от 1 дня до любого количества дней
- **Уровни логирования**: DEBUG, INFO, WARNING, ERROR, CRITICAL
- **Множественный вывод**: одновременно в файл и консоль
- **Административные команды**: мониторинг через Telegram
- **Умная очистка**: сохранение места на диске

### Регулярные встречи
- **6 типов повторений**: ежедневно, еженедельно, раз в 2 недели, ежемесячно, по будням, по выбранным дням
- Настраиваемый интервал повторения (каждые N дней/недель/месяцев)
- Интерактивный выбор дней недели для кастомных расписаний
- Опциональная дата окончания серии встреч
- Автоматическое создание следующих встреч в серии
- Сохранение регулярных встреч при очистке прошедших
- Умная логика пропуска выходных для рабочих встреч
